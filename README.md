# 听课台

实时课堂转录、双语翻译和学习笔记，整个应用就是一个 `index.html`，不需要构建。

**在线演示：** https://yuqi27116-eng.github.io/tingketai/

打开后点「▶ 演示课堂」，可以不说话就看到一段西语生理课的完整流程：边听边转录和翻译、课件自动翻页、老师提问、重点、纲要，结束后进入复习模式（思维导图、逐字稿、课件、重点联动）。演示用的是预设的 AI 结果。

## 用自己的 key

在网页版里，AI 和语音转写用的是你自己的账户，在工具栏「接口」里填：

| 用途 | 填什么 |
|---|---|
| 翻译、笔记、思维导图、提问、问 AI | Anthropic API key（通过官方 `@anthropic-ai/sdk` 在浏览器里调用，默认 Claude Opus 5.5） |
| 导入录音转写、补转切到后台时的那段 | Whisper 兼容的语音转写 key（OpenAI 或 Groq） |

key 只保存在你这台电脑的浏览器里（localStorage），不会上传到任何服务器。这是纯前端页面，任何人打开这个链接看到的都是自己浏览器里的数据。

不填 key 时，听写（Chrome 自带的语音识别）、本机录音、课件定位、我的笔记、分段等功能照样可以用，只是没有翻译和 AI 笔记。

## 浏览器

请用电脑版 Chrome 或 Edge：实时听写依赖浏览器的语音识别，录音存在浏览器的 IndexedDB 里。

## 主要功能

- 实时转录 + 双语翻译（合并请求，同一时间只有一个翻译请求）
- 课件视窗：PDF / PPTX，自动定位老师讲到哪一页、哪一行（本机计算，不花 token）
- 老师提问：本机即时识别，判断问题是否说完，带前后文；AI 给出精确 / 简单 / 保守三种回答
- 每分钟纲要和重点、AI 笔记、思维导图、问 AI
- 复习模式：思维导图、逐字稿、录音、课件、重点点任意一处，其他联动
- 我的笔记：仿 Obsidian 的笔记库，`[[双链]]`、`#标签`、反向链接、关系图
- 导入录音转写、断网排队、限速自动退避、切到后台用录音补转
